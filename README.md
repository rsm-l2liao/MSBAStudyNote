# Data Analysis Learning Notes

# 数据分析学习笔记

---

## About | 关于项目


This repository contains my learning notes as I study data analysis from scratch.
It is designed to help me review and consolidate what I’ve learned, while also serving as a resource for others—especially those who want to learn data analysis in a bilingual (English + Chinese) environment.


本仓库记录了我从零开始学习数据分析的学习笔记。
一方面用于我个人复习与巩固知识，另一方面也希望能够帮助更多使用中英文双语学习数据分析的人。

---

* Build a solid foundation in data analysis 打好数据分析基础
* Document key concepts, code examples, and workflows 记录核心概念、代码示例和分析流程
* Practice thinking in both English and Chinese 训练中英文双语思维
* Create a structured and reusable knowledge base 构建可复用的知识体系
